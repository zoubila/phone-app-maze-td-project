RESSOURCES DE MAZE TD — PIXEL ART

Chaque objet utilisé par le jeu possède maintenant son propre PNG transparent.
Les unités sont sur une toile de 320 x 320 pixels, sans lissage ni changement d'échelle.

Le chemin est dessiné par scenery.gd, pour suivre le trajet réel des monstres
après les constructions. Son bord rejoint le sol par des pixels d'herbe.
Les panneaux et boutons sont dessinés séparément par l'interface Godot.
La flèche est dessinée en petits rectangles par projectiles.gd.

sources/pixelart/
  sprites_reference.png   Planche originale conservée comme référence seulement.
  sol_reference.png       Original du sol.
sources/pixelart_prompts.json  Instructions de génération.
Le dossier sources/ est exclu de l'import Godot par .gdignore.
Les anciens fichiers cartoon restent archivés dans les dossiers existants.

POUR TES ANIMATIONS
Ouvrir le PNG du personnage concerné dans Aseprite, jamais la planche globale.
Conserver le même cadrage et le même point d'appui entre toutes les images.
La base générée est détaillée : pour une animation simple, la redessiner en
32 x 32 ou 48 x 48 pixels, sans lissage, puis conserver le fichier .aseprite
dans sources/ennemis/ et exporter les PNG dans le dossier de l'ennemi.
Nommer les animations repos, marche, attaque, mort et noter la cadence choisie.
Pour une suite PNG : gobelin_marche_01.png, gobelin_marche_02.png, etc.
Pour une planche par animation : gobelin_marche_sheet.png, avec dimensions
de cellule, nombre d'images et cadence dans un fichier gobelin_marche.txt.


ANIMATION INTÉGRÉE : GOBELIN
terrestres/gobelin_marche_01.png à gobelin_marche_08.png, dans ennemis/,
sont les huit images actives de la marche. Garder leur cadrage commun
de 320 x 320 pixels et leurs fonds transparents lors des retouches.
La copie Piskel de travail est conservée dans
sources/ennemis/gobelin/gobelin_marche.piskel, exclu de l'import Godot.
La planche gobelin_marche_sheet.png sert seulement à l'édition Piskel ;
le jeu charge chaque PNG individuel, sans découpage à l'exécution.
